================================================================================
  EduFlow AI - RAG System Setup Guide for New Team Members
  Follow these steps EXACTLY after pulling the code from GitHub
================================================================================


--------------------------------------------------------------------------------
STEP 1 — Pull the latest code
--------------------------------------------------------------------------------

  git pull


--------------------------------------------------------------------------------
STEP 2 — Set up Python Virtual Environment (only do this ONCE)
--------------------------------------------------------------------------------

  Open a terminal and navigate to the ai-agent folder:

    cd "YOUR_PROJECT_PATH\ai-agent"

  Create the virtual environment:

    python -m venv .venv

  Install all required packages:

    .venv\Scripts\pip install -r requirements.txt


--------------------------------------------------------------------------------
STEP 3 — Create your .env file (REQUIRED - this file is NOT in GitHub)
--------------------------------------------------------------------------------

  Copy the example file:

    copy .env.example .env

  Open the .env file in any text editor (Notepad, VS Code, etc.)
  and fill in your API key. You need at least ONE of these (both are FREE):

  OPTION A - Use Groq (Recommended - very fast responses):
    Get your free key at: https://console.groq.com/keys

    Set these values in .env:
      LLM_PROVIDER=groq
      GROQ_API_KEY=gsk_your_key_here
      GROQ_MODEL=openai/gpt-oss-120b

  OPTION B - Use Google Gemini:
    Get your free key at: https://aistudio.google.com/app/apikey

    Set these values in .env:
      LLM_PROVIDER=gemini
      GEMINI_API_KEY=AIza_your_key_here
      GEMINI_MODEL=models/gemini-flash-latest

  Also make sure these lines are in your .env (copy from .env.example if missing):
      EMBEDDING_PROVIDER=default
      CHROMA_PERSIST_DIR=./data/chroma_db
      INTERNAL_SERVICE_TOKEN=<generate-a-random-token; must match backend AiService:ApiKey>


--------------------------------------------------------------------------------
STEP 4 — Get the PDF lecture files (REQUIRED - PDFs are NOT in GitHub)
--------------------------------------------------------------------------------

  Ask your team member (Atheek) to share the PDF files from:
    Project\backend\EduFlow.Api\wwwroot\uploads\pdfs\

  Copy those PDF files into YOUR machine at the same path:
    YOUR_PROJECT_PATH\backend\EduFlow.Api\wwwroot\uploads\pdfs\

  If the folder does not exist, create it manually.


--------------------------------------------------------------------------------
STEP 5 — Run the Setup Checker (checks everything + auto-indexes PDFs)
--------------------------------------------------------------------------------

  Make sure you are in the ai-agent folder, then run:

    .venv\Scripts\python.exe setup_check.py

  This script will automatically:
    [1] Check all Python packages are installed correctly
    [2] Check your .env file exists and API keys are valid
    [3] Check PDF files exist in the uploads folder
    [4] Auto-index all PDFs into ChromaDB vector database
    [5] Run a live test question and show you the AI answer with slide citations

  If all steps pass, you will see this at the end:
    "ALL CHECKS PASSED! Your RAG system is ready."

  If any step fails, the script will tell you exactly what to fix.


--------------------------------------------------------------------------------
STEP 6 — Start the full application
--------------------------------------------------------------------------------

  Go back to the ROOT project folder:

    cd ..

  Start all three services (Frontend + Backend + AI) with one command:

    npm run dev

  Wait until you see all three services started. Then open your browser:

    Frontend  :  http://localhost:2174   (or http://localhost:5173)
    AI Docs   :  http://localhost:8000/docs
    Backend   :  http://localhost:5204/swagger


--------------------------------------------------------------------------------
STEP 7 — Test the RAG system in the app
--------------------------------------------------------------------------------

  1. Open http://localhost:2174 in your browser
  2. Log in with a student account
  3. Go to the Student page
  4. Click on "AI Learning Assistant" tab
  5. Type any question about the course, for example:
       "explain machine learning"
       "what is supervised learning?"
       "what topics are in this lecture?"
  6. You should see an AI answer with slide citation badges at the bottom

================================================================================
  COMMON ERRORS AND FIXES
================================================================================

  ERROR: "No indexed lectures are available yet"
  FIX: You skipped Step 4 or Step 5. Make sure PDFs are in the uploads folder
       and run setup_check.py to index them.

  ERROR: "GROQ_API_KEY is empty"
  FIX: You did not fill in your API key in the .env file. See Step 3.

  ERROR: "Module not found" or "Import error"
  FIX: You skipped Step 2. Run:  .venv\Scripts\pip install -r requirements.txt

  ERROR: AI returns "I'm your EduFlow AI Learning Coach! Keep completing lessons..."
  FIX: This is a fallback message. It means the .NET backend cannot reach the
       Python AI service. Make sure you are running npm run dev from the ROOT
       folder (not from inside the frontend folder).

  ERROR: Port already in use
  FIX: Another process is using that port. Run:
       netstat -ano | findstr :8000
       Then kill that process ID using Task Manager.
