# Member 1 Allocation: User & Course Management

## Overview
**Focus Area:** Core user identities (Students, Instructors, Admins), course catalogs, enrollments, and profiles.

## Technical Responsibilities
* **Backend & DB (ASP.NET Core / PostgreSQL):** 
  * Design schemas and APIs for `Users`, `Roles`, `Courses`, `Modules`, and `Enrollments`.
  * Implement JWT Authentication and secure routing.
* **React Web Application:** 
  * Build an Admin/Instructor dashboard for user management and course creation.
* **Flutter Mobile Application:** 
  * Develop the Student view for browsing the course catalog and managing their user profile.

## Agentic AI Contribution
**Role:** Coordinator / Planner Agent ("Course Architect")
* **Description:** Receives raw text prompts from users (e.g., "Create a Python crash course"). Analyzes the objective, generates a structured multi-step plan, and delegates specific tasks to other agents.
* **Rubric Alignment:** Fulfills the "planning and delegation" requirement of the minimum assessed workflow.
