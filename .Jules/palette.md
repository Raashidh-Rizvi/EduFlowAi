## 2024-05-18 - Keyboard Accessibility for Custom Interactive Cards
**Learning:** Custom interactive "cards" (like the demo account selection in the Login screen) are often implemented using `<div>` tags with `onClick` handlers. While visually appealing, this breaks keyboard accessibility (Tab/Space/Enter navigation) and screen reader functionality. Since this pattern is common in React applications like this one, it is critical to ensure these elements use semantic `<button type="button">` tags.
**Action:** When creating or reviewing custom interactive card components in this app, always ensure they are wrapped in semantic `<button>` elements with `type="button"` and include appropriate inline styles (e.g., `width: 100%`, `text-align: left`) to override default button browser styling while retaining native accessibility benefits.
