# EduFlow AI — Flutter Mobile

The repository contains learner screens, API/auth/gamification services and test files. Their presence supersedes old blanket claims that no API service exists, but does not establish a fully verified cross-platform workflow. Mobile was not runtime-tested in the Learning documentation workstream.

From `mobile/`:

```powershell
flutter pub get
flutter run
flutter test
```

Use actual emulator/device backend configuration and private session handling. Commands are not recorded passing results.
