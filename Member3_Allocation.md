# Member 3 Allocation: Gamification & Engagement

## Overview
**Focus Area:** Points, badges, streaks, leaderboards, and student engagement tracking.

## Technical Responsibilities
* **Backend & DB (ASP.NET Core / PostgreSQL):** 
  * Design schemas and APIs for `Badges`, `UserPoints`, `Leaderboards`, and `Achievements`.
* **React Web Application:** 
  * Build the Admin interface to define gamification rules and view overall engagement metrics.
* **Flutter Mobile Application:** 
  * Develop an interactive mobile view for students to see their earned badges, streaks, and current leaderboard rank.

## Agentic AI Contribution
**Role:** Domain Analysis Agent ("Engagement Analyzer")
* **Description:** Analyzes domain-specific data. It evaluates the generated course and quizzes to recommend and attach appropriate gamification rewards (e.g., dynamically assigning a 'Python Pioneer' badge upon completion of the generated quizzes based on difficulty).
* **Rubric Alignment:** Fulfills the "domain analysis" requirement of the minimum assessed workflow.
