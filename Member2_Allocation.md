# Member 2 Allocation: Assessments & Quizzes

## Overview
**Focus Area:** Managing quizzes, questions, student submissions, and grading.

## Technical Responsibilities
* **Backend & DB (ASP.NET Core / PostgreSQL):** 
  * Design schemas and APIs for `Quizzes`, `Questions`, `Submissions`, and `Grades`.
* **React Web Application:** 
  * Build the Instructor interface with forms to build and manage quizzes.
* **Flutter Mobile Application:** 
  * Develop the Student interface to take timed quizzes and view immediate results.

## Agentic AI Contribution
**Role:** Action / Tool Agent ("Quiz Master")
* **Description:** Uses strictly allow-listed tools to execute actions. It receives the plan from the Planner Agent and utilizes specific tools (like LLM content generation or web search) to automatically generate quiz questions and answers based on the course topic.
* **Rubric Alignment:** Fulfills the "controlled tools" and "action" requirement of the minimum assessed workflow.
